# Teamplay Talk Icon

Concept: **Converging Liquid Lenses**.

The icon uses large slanted lens shapes instead of literal dots, lines, chat bubbles, checkmarks, or AI sparkles. Each lens is a distinct teammate/input layer. The lenses sit on one elliptical orbit and converge toward a subtle center decision surface, so the mark reads as separate signals becoming one coordinated system.

## Why This Direction

The previous organic membrane concept became too hand-drawn and fragile. This version is generated by `generate_icon_layers.py` from one compositional function: orbit position, tangent rotation, perspective depth, and center binding. It is better for Apple Icon Composer because each visible element is a simple independent layer that can receive depth, glass, lighting, and appearance-mode treatment.

## Icon Composer Import Layers

Import these SVGs in this order. Each uses a 1024 x 1024 canvas with transparent background.

1. `layers/01_lens_idea.svg`
2. `layers/02_lens_coordination.svg`
3. `layers/03_lens_decision.svg`
4. `layers/04_lens_handoff.svg`
5. `layers/05_decision_surface.svg`

Do not export a rounded rectangle or circle mask. Icon Composer applies the platform mask later.

## Layer Intent

- Purple lens: idea/input signal.
- Blue-violet lens: coordination signal.
- Yellow lens: decision/agenda energy.
- Orange lens: action/handoff energy.
- Center surface: very subtle binding layer, not a fifth object.

Suggested Icon Composer tuning:

- Give each lens its own depth so the icon feels stacked, not flat.
- Use Liquid Glass material on the lenses, not on a single enclosing blob.
- Keep the center decision surface shallow and translucent.
- Keep shadows soft and system-generated.
- Avoid hand-drawn highlights in source layers. The preview SVG includes highlights only to show the intended final mood.
- Check Default, Dark, Tinted, and Clear/Mono modes before final export.
